Package

scDiagnostics

Diagnostic functions for assessing the quality of cell type annotations in single-cell RNA-seq data. Developed at the Core for Computational Biomedicine, Harvard Medical School.

Bioconductor Source Paper
Companion application

scDiagnosticsApp

An interactive interface to scDiagnostics. The application can be deployed locally from source, or accessed through the hosted instance at Harvard Medical School.
